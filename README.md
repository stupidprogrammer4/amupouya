# Pouya Sadeghi · amupouya.org

My personal website: selected backend work, Python tools, engineering interests, and a little life beyond the keyboard. A responsive static site with dark and light themes, self-hosted fonts, and no runtime API dependencies.

Run locally with `python3 -m http.server 4173`, then open `http://localhost:4173`. The page works without JavaScript; JavaScript adds the mobile menu, saved theme preference, and email-copy action.

GitHub Pages publishes the root of `main` to the custom domain in `CNAME`. Font licenses live in `static/fonts/`. The butterfly artwork was generated for this website and is served as an optimized WebP.
